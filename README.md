Slideshow Plugin for BakeKit

The `Slideshow` plugin allows you to create and manage image slideshows or carousels in [BakeKit CMS](https://github.com/bakewizard/BakeKit).

## Features

- Add/edit slides with titles, descriptions, images
- Add custom links, or links from plugin actions that are automatically generated
- Output slides using blocks (cells)

## Installation

You can install this plugin via the BakeKit Admin Panel by uploading the plugin zip.
